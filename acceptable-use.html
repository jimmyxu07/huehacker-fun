Acceptable Use Policy

Last updated: May 2026

This policy explains what behavior is and isn’t allowed when using Hue Hacker.

Allowed use

  • Playing the color calibration game in a web browser.
  • Sharing links to the Site.
  • Inspecting the client-side code for learning purposes.
  • Forking or building on the open-source code under its license.

Prohibited use

  • Scraping or crawling: Automated bulk extraction of Site assets, text, or code is not allowed.
  • Reverse engineering: Decompiling or tampering with the delivery pipeline or obfuscated assets to exploit the Site.
  • Abuse of infrastructure: Using bots, scripts, or other automation to generate excessive requests against GitHub Pages.
  • Misrepresentation: Claiming affiliation with Hue Hacker or presenting modified copies as the original.
  • Illegal activity: Any use that violates applicable laws.

Enforcement

We may block access or report abuse to GitHub or relevant authorities if we detect violations. Because the Site is static and free, our primary remedy is blocking abusive traffic patterns.

Reporting abuse

If you discover abuse or misuse, please report it via the GitHub repository or the contact method on huehacker.fun.
